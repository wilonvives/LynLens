# 通用 (Default) Packaging Template

## 风格定位

LynLens 的基线模板. 任何视频开箱即用 — 不会出错, 不会用力过猛.

**适合**:
- 短视频 / 中视频 / 长视频都行
- 科普 / 访谈 / 教程 / Vlog / 评测
- 不确定该用什么风格时的安全选择

**不适合**:
- 想要"网感爆款"效果 → 用 `energetic`
- 文艺 / 治愈系 → 等 v0.7 的 `gentle` 模板

如果你的视频内容偏严肃 / 平淡, 用这个; 偏情绪 / 钩子, 用 `energetic`.

---

## 关键词挑选规则

**每段 0-2 个**. 大部分段可能只挑 1 个或不挑.

挑选优先级:
1. **数字** — "3 个", "10 万", "第一" (具体, 视觉记忆点)
2. **品牌 / 人名 / 专有名词** — "SLAPP", "苹果", "马斯克"
3. **情绪强词** — "可怕", "崩溃", "震惊" (用得少, 不滥用)
4. **动词高潮** — "爆", "崩" (用得最少)

**关键**: 通用模板偏保守. 看到不确定的词宁可不挑, 别硬加.

**避免**:
- 代词 / 助词 / 副词
- 连接词 ("但是", "所以", "因此")
- 时间副词除非语义关键

---

## 颜色规则

Palette: `["#ffd700"]` — **只有一个色** (金色).

为什么单色? 通用模板的目标是"不出错". 多色 palette 容易跟视频背景冲突; 单色金黄在大部分场景都醒目, 也不会让画面乱.

如果想要彩色, 用 `energetic` 模板.

---

## 字号规则

- 默认字号 = manifest.subtitle.defaults.size (56)
- 关键词字号 = 56 × 1.2 ≈ 67 px
- 比默认稍大, 但不夸张 — 与默认值的对比度足够让眼睛识别, 又不会喧宾夺主.

**不要主动设 `size`**, 让 runtime 按 sizeBoost 算.

---

## 节奏指导

不需要. 通用模板**不输出** camera / transition / audio 相关字段. 让画面安静, 主角是字幕.

---

## 例子

### 例 1 — 一个数字
**输入**: "今天讲三个案例"
- "三个" — 数字 → `#ffd700`

```json
{
  "segmentIdx": 0,
  "subtitle": {
    "wordEffects": [
      { "wordIdx": 2, "highlight": "#ffd700" }
    ]
  }
}
```

### 例 2 — 一个品牌名
**输入**: "苹果发布会刚结束"
- "苹果" — 品牌 → `#ffd700`

### 例 3 — 平淡, 不挑
**输入**: "我们继续看下一个"
- 全是代词 / 助词. **不输出此段**.

### 例 4 — 两个关键词 (上限)
**输入**: "SLAPP 在 10 万案例里出现过"
- "SLAPP" — 品牌 → `#ffd700`
- "10 万" — 数字 → `#ffd700`

(注意: palette 单色, 两个词都金色. 不要为了"换色"而引入 palette 外的颜色.)

---

## 反例

❌ 加情绪词到平淡段:
**输入**: "这个数据非常重要"
- 不要把 "非常" 或 "重要" 挑出来. "非常" 是程度副词, "重要" 太抽象.
- 应该: 不挑.

❌ 一段挑超过 2 个:
- max = 2, 严格遵守.

❌ 用 palette 之外的颜色:
- palette 就一个 #ffd700, 不要因为段里有动词就用红色. 改用 `energetic` 模板.

---

## 输出格式

同 LynLens PackagingPlan schema. 只列要改的段, 其他段不写.

```ts
{
  segmentIdx: number,
  subtitle?: {
    wordEffects?: Array<{
      wordIdx: number,
      highlight?: string
    }>
  }
}
```

**不要**输出 `subtitle.color`, `subtitle.position`, `subtitle.size` 等全行字段 — 通用模板的整体样式在 manifest.subtitle.defaults 里定死, 段级别只调关键词.
