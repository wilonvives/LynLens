# 高能 (High-Energy) Packaging Template

## 风格定位

视频氛围: **大字 + 鲜艳色 + 密集关键词**, 让观众停下来看. 灵感来自抖音/视频号上"控诉 / 警示 / 爆点"类内容 (例: 法律科普讲 SLAPP / 金融骗局揭露 / 健康警告).

**适合**:
- 钩子段 (前 3-10 秒"你不敢相信...")
- 情绪反转 / 爆点段 ("结果没想到的是...")
- 揭露 / 控诉 / 警示
- 节奏快, 情绪饱满的内容

**不适合**:
- 长访谈 / 圆桌对话
- 平铺直叙的解释段 (会显得用力过猛)
- 教学 / 课程 (字太多干扰理解)
- 文艺 / 治愈系内容

判断: 这段如果在 TikTok / 抖音刷到, 观众会想停下来听完? 是 → 高能值得用. 否 → 用 通用 模板.

---

## 关键词挑选规则

**每段挑 2-3 个关键词** (vs 通用模板的 0-2). 这是高能比通用更"密"的核心.

但**不是每段都挑** — 平铺直叙的解释段、过渡段就**完全不要花字**, 让金句段自己跳出来. 如果一段实在没值得挑的词, 就不输出该段的 segments 条目.

挑选优先级 (按 manifest.subtitle.keywords.categoriesByPriority):

1. **情绪强词** — 让观众生理反应的词. "噩梦", "可怕", "崩溃", "爽", "神", "炸裂", "震惊", "痛", "惨".
2. **动词高潮** — 带画面的动作词. "爆", "崩", "炸", "杀", "抢", "拽", "砸", "撕".
3. **数字** — 具体, 视觉记忆点. "3 个", "10 万人", "第一", "全网", "100%".
4. **品牌 / 人名 / 专有名词** — 观众记得的实体. "SLAPP", "苹果", "马斯克".

(注意优先级与 通用 不同 — 通用是数字优先, 高能是情绪优先, 因为高能要的就是情绪冲击.)

**避免挑**:
- 代词 (我, 你, 这, 那) — 没有信息量
- 时间副词 (现在, 已经, 突然) — 除非语义关键
- 程度副词 (很, 非常, 极其) — 没有画面感
- 助词 / 语气词 (了, 吗, 啊, 嘛)
- 连接词 (但是, 所以, 因此) — 结构词, 不该被放大

## 颜色规则

Palette: `["#ff3333", "#ffd700", "#ff6b00"]` — 红 / 金 / 橙, 三色轮换.

按词性映射:
- 情绪强词 / 动词高潮 → **红色 `#ff3333`** 优先, 次选 **橙 `#ff6b00`**
- 数字 / 品牌名 → **金色 `#ffd700`**
- 段内**第二个**关键词 → 选 palette 里**没用过**的色 (避免一段两个同色显得单调)

**禁止**:
- 改全段颜色 (`subtitle.color`) — 整体白字是基线
- 改描边色 (`outline.color`) — 永远黑色
- 使用 palette 外的颜色 (绿/紫/粉等)
- 段内三个关键词全用同一颜色

---

## 字号规则

- 默认字号 = `manifest.subtitle.defaults.size` (64 px @ 1080p)
- 关键词字号 = default × `sizeBoost` (= 64 × 1.3 ≈ 83 px)

**不要主动设 `size`**, 让 runtime 按 sizeBoost 自动算. 主动设可能跨分辨率失真, 也容易触发"字太大爆框"的 cap.

实测 83 px 在 1080×1920 portrait 上 ≈ 4.3% 帧高, 一段最多 3 个加大词, 不会撑爆.

## 例子

### 例 1 — 情绪词 + 数字 (高能的典型钩子段)
**输入**: "今天讲一个**很可怕**的事情, 涉及**3 万**人"

挑选:
- "可怕" — 情绪强词 (优先级 1) → 红 `#ff3333`
- "3 万" — 数字 (优先级 3) → 金 `#ffd700` (palette 里没用过红, 用金)

输出:
```json
{
  "segmentIdx": 0,
  "subtitle": {
    "wordEffects": [
      { "wordIdx": 3, "highlight": "#ff3333" },
      { "wordIdx": 7, "highlight": "#ffd700" }
    ]
  }
}
```

### 例 2 — 三个关键词 (上限)
**输入**: "**苹果****炸了**网络, **10 亿**人围观"

挑选:
- "苹果" — 品牌 (优先级 4) → 金
- "炸了" — 动词高潮 (优先级 2) → 红 (palette 里没用过, 优先红)
- "10 亿" — 数字 (优先级 3) → 橙 (避免重复红/金)

```json
{
  "subtitle": {
    "wordEffects": [
      { "wordIdx": 0, "highlight": "#ffd700" },
      { "wordIdx": 1, "highlight": "#ff3333" },
      { "wordIdx": 3, "highlight": "#ff6b00" }
    ]
  }
}
```

### 例 3 — 平淡过渡, 不挑
**输入**: "刚才说的就是这个意思"

全是助词 / 代词. **不输出此段**, runtime 用默认样式 (白字底部).

### 例 4 — 钩子段 (情绪超强)
**输入**: "**100%** 你**不敢**想的**真相**"

挑选:
- "100%" — 数字 → 金
- "不敢" — 情绪强词 → 红 (优先级 1, 选红)
- "真相" — 情绪强词 → 橙 (palette 里 红已用, 选橙)

## 反例 (不要这么做)

❌ 全段染色:
```json
{ "subtitle": { "color": "#ff3333" } }   // 错: 不要全行覆盖
```
应: 只挑关键词改色, 其他字保持白色.

❌ 一段挑 5 个词:
```json
{ "wordEffects": [{...},{...},{...},{...},{...}] }   // 错: 超过 max=3
```
应: 最多 3 个, 挑最重要的.

❌ 段内同色重复:
```json
{ "wordEffects": [
  { "wordIdx": 0, "highlight": "#ff3333" },
  { "wordIdx": 3, "highlight": "#ff3333" }   // 错: 段内同色
] }
```
应: palette 里轮换没用过的色.

❌ 把代词 / 助词加花字:
**输入**: "**这**是一个例子" → wordIdx 0 = "这"
错. "这" 是代词. 应跳过, 段里没值得挑的就不输出 segments 条目.

❌ 用 palette 外的颜色:
```json
{ "highlight": "#00ff00" }   // 错: 绿色不在 palette
```
应: 只用 ["#ff3333", "#ffd700", "#ff6b00"] 三色.

❌ 主动设 size:
```json
{ "wordIdx": 0, "highlight": "#ff3333", "size": 100 }   // 错: 让 runtime 按 sizeBoost 算
```
应: 不设 size, runtime 自动算 64 × 1.3.

## 输出格式

按 LynLens PackagingPlan JSON schema. 顶层只关心 `segments` 数组. 每段:

```ts
{
  segmentIdx: number,         // 对应 transcript.segments[i] 的 index
  subtitle?: {
    wordEffects?: Array<{
      wordIdx: number,         // 词 index (空格分词, CJK 整段 = wordIdx 0)
      highlight?: string       // hex 颜色, 必须在 palette 内
      // 不要设 size — 让 runtime 按 sizeBoost 算
    }>
  }
}
```

**只列你要改的段**. 其他段不写, runtime 用 defaults.

## 我和 通用 模板的区别 (给作者参考)

| 维度 | 通用 | 高能 |
|---|---|---|
| 关键词数 | 0-2/段 | 2-3/段 (密集) |
| Palette | 单色金 `["#ffd700"]` | 三色 `["#ff3333", "#ffd700", "#ff6b00"]` |
| 优先级 | 数字 > 品牌 > 情绪 | 情绪 > 动词 > 数字 > 品牌 |
| sizeBoost | 1.2 | 1.3 |
| 默认 size | 56 | 64 |
| 描边 width | 3 | 4 |

设计哲学: 通用偏可读性 / 安全; 高能偏情绪冲击 / 密度. 视频不是钩子 / 爆点类型, **不要选高能**.
